# MiniLang Custom Keywords

This project uses a custom keyword set for the personalized MiniLang variant.

| Custom Keyword | Meaning |
|---|---|
| text | string data type |
| num | integer data type |
| decimal | decimal data type |
| logic | boolean data type |
| yes | true value |
| no | false value |
| check | if statement |
| otherwise | else statement |
| do | do-while loop |
| during | while condition |
| func | function declaration |
| give | return statement |
| show | print/output statement |
| stop | break statement |
| skip | continue statement |
| record | record/struct declaration |
| start | program start |

## Variant 3 Features

The language variant for this project supports:

1. Strings
2. String concatenation using `+`
3. Do-while loops
4. Short-circuit logical AND `&&`
5. Short-circuit logical OR `||`
